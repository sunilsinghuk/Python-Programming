# Python Programming Repository

## Overview
Welcome to the **Python Programming** repository! This repository contains structured lecture content, practical exercises, and Jupyter notebooks for learning Python programming. The content is divided into multiple units covering Python fundamentals, Pandas, NumPy, and visualization libraries like Matplotlib and Seaborn.

## Repository Structure
The repository is organized into separate folders for each major topic:
- **Python Basics**: Covers core Python programming concepts.
- **Pandas Library**: Contains lecture content related to data manipulation with Pandas.
- **NumPy Library** (Coming Soon)
- **Visualization Libraries** (Matplotlib & Seaborn) (Coming Soon)

Each folder contains Google Colab notebooks corresponding to the lectures in the course.
